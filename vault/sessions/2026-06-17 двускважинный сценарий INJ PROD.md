# 2026-06-17 — Двускважинный сценарий INJ + PROD

## Задача
Реализовать и протестировать сценарий с двумя скважинами (нагнетательная + добывающая) при открытых границах (давление на контуре питания).

## Что сделано

### TwoWellCase
- INJ при x = Nx/4, PROD при x = 3Nx/4, обе на y = Ny/2
- Q = 50 м³/сут (объёмный расход), 63×63 ячеек, 730 дней
- Открытые границы (P = P_init на контуре)
- INJ закачивает воду: `water_mass_rate = -Q·ρ_w`
- PROD добывает нефть: `oil_mass_rate = Q·ρ_o`

### Обобщение инфраструктуры тестов
- `SimulationCase`: добавлены виртуальные `nx()`, `ny()`, `lx()`, `ly()`, `wells_info()`
- `run_single_injector()` → `run_case()` — принимает `SimulationCase&`
- `write_metadata_json()` — массив `wells` с именем, типом, координатами
- `animate_fields.py` — маркеры скважин: ▼ синий (INJ), ▲ красный (PROD)

### Результаты (63×63, Q=50, 730 дней)
- 0 rollback, Newton 1 итерация
- Oil: 80 → 52 ×10⁶ кг, Water: 25 → 60 ×10⁶ кг
- Невязка баланса ~0.03 кг (≈ 4e-10 относительная)
- Водный фронт прорывается к PROD и через контур (~550 дней)
- Давление: купол у INJ (~210 атм), воронка у PROD (~165 атм)

### Исследование вариантов (до финальной реализации)
- Q = 5 м³/сут, 21×21, 100 дней — работает
- Q = 50 м³/сут, 21×21, 100 дней — работает
- Q = 50 м³/сут, 63×63, 365 дней — работает
