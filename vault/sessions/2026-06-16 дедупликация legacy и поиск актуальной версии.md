# 2026-06-16 — Дедупликация legacy и поиск актуальной версии

## Цель сессии
Разобраться с папкой `legacy/` — найти и убрать дубликаты файлов, определить самую актуальную версию симулятора.

## Структура legacy до начала работы
4 подпроекта, ~59 000 файлов (включая build-артефакты):
- **PCNAC** — 4 725 исходных файлов
- **PC-Nuts** — 3 965 исходных файлов
- **BVPSolver** — 405 исходных файлов (не трогали)
- **PCNAC_old** — 251 исходный файл

## Что сделано

### 1. PCNAC_old — удалена
- 172 из 251 файлов — точные копии из PCNAC/PC-Nuts
- 79 уникальных файлов (60 после внутренней дедупликации Shared0 ↔ HydroSolver)
- Уникальные сохранены в `_saved_from_PCNAC_old/`
- Папка удалена пользователем

### 2. PC-Nuts\Code и PC-Nuts\Project3 — удалены
- `Code/`: 73 файла, 12 уникальных → `_saved_from_PC-Nuts_Code/`
- `Project3/`: 74 файла, 25 уникальных → `_saved_from_PC-Nuts_Project3/`
- Папки удалены пользователем

### 3. Точечная чистка пересечений PC-Nuts ↔ PCNAC
- `PC-Nuts\Timur` ↔ `PCNAC\TestFiles` — 13 111 общих файлов
- `PC-Nuts\Code2` ↔ `PCNAC\Repo` — 769 общих файлов
- Решение: оставить PC-Nuts\Timur и PCNAC\Repo
- Уникальные файлы из удаляемых папок сохранены:
  - `PCNAC\TestFiles` (8 819 уникальных) → `_saved_from_PCNAC_TestFiles/`
  - `PC-Nuts\Code2` (88 уникальных) → `_saved_from_PC-Nuts_Code2/`
- `PC-Nuts\testGEOSlib` (5 файлов, все дубли) — удалена
- Папки `PCNAC\TestFiles`, `PC-Nuts\Code2`, `PC-Nuts\testGEOSlib` удалены пользователем

### 4. Определена самая актуальная версия
- **`PCNAC\Repo\GDM\`** — самая свежая и полная (конец 2022)
  - 125 собственных исходников (без amgcl)
  - HydroSolver.sln + .vcxproj
  - Shared0 (Utils)
  - AMGSolver (amgcl)
  - Модули: Data, Descriptors, Reservoir, Solver, Anomaly, Helpers, tests
  - Ключевые фичи: Factory-паттерн, CSR-матрица, CalculationManager, фазовые свойства, юнит-тесты
- **`PC-Nuts\HydroSolver`** — ранняя версия (2021), полезна как исторический снимок

## Текущее состояние legacy
- `PC-Nuts/` — Timur (GUI), HydroSolver (ранний снимок), Project1, Project2, Documentation и др.
- `PCNAC/` — Repo (актуальная версия), auxFiles, Support, VPNFiles
- `BVPSolver/` — не трогали, разберёмся позже
- `_saved_from_*` — папки с уникальными файлами из удалённых директорий
- Списки дублей и уникальных файлов — `.txt` файлы в корне legacy

## Перенос в корень проекта (вторая часть сессии)

Legacy-файлы перемещены пользователем в `Support/legacy/`.

Из `Support/legacy/PCNAC/Repo/` в корень проекта скопированы:
- `HydroSolver/` — 126 собственных исходников + AMGSolver (amgcl)
- `Shared0/` — 18 файлов общих утилит
- `GridEngine/` — 12 файлов, парсер сеточных данных GRDECL (формат ECLIPSE)
- `MatLab/` — 14 файлов, скрипты визуализации из ранней версии
- `HydroSolver.sln` — файл решения VS для справки о зависимостях
