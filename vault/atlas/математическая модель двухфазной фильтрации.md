# Математическая модель двухфазной фильтрации

## Уравнения неразрывности

Для несжимаемых фаз (нефть $o$ и вода $w$) уравнения неразрывности имеют вид:

$$\phi \frac{\partial S_\alpha}{\partial t} + \nabla \cdot \mathbf{u}_\alpha = q_\alpha, \quad \alpha \in \{o, w\}$$

где $\phi$ — пористость, $S_\alpha$ — насыщенность фазы $\alpha$, $\mathbf{u}_\alpha$ — скорость фильтрации, $q_\alpha$ — источниковый член (скважины).

Условие замыкания по насыщенностям:

$$S_o + S_w = 1$$

## Закон Дарси для многофазной фильтрации

Скорость фильтрации каждой фазы определяется обобщённым законом Дарси:

$$\mathbf{u}_\alpha = -\frac{k \, k_{r\alpha}(S_w)}{\mu_\alpha} \left( \nabla p_\alpha - \rho_\alpha g \nabla z \right)$$

где $k$ — абсолютная проницаемость, $k_{r\alpha}$ — относительная фазовая проницаемость, $\mu_\alpha$ — вязкость, $p_\alpha$ — давление фазы, $\rho_\alpha$ — плотность, $g$ — ускорение свободного падения.

## Замыкающие соотношения

### Капиллярное давление

$$p_c(S_w) = p_o - p_w$$

### Относительные фазовые проницаемости — модель Кори

$$k_{rw}(S_w) = k_{rw}^{max} \left( \frac{S_w - S_{wc}}{1 - S_{wc} - S_{or}} \right)^{n_w}$$

$$k_{ro}(S_w) = k_{ro}^{max} \left( \frac{1 - S_w - S_{or}}{1 - S_{wc} - S_{or}} \right)^{n_o}$$

где $S_{wc}$ — связанная водонасыщенность, $S_{or}$ — остаточная нефтенасыщенность, $n_w, n_o$ — показатели Кори.

### Модель Брукса–Кори

Альтернативная параметризация с входным капиллярным давлением $p_e$ и параметром распределения пор $\lambda$.

## Начальные условия

- Начальное распределение давления $p(x, t=0) = p_0(x)$
- Начальное распределение насыщенности $S_w(x, t=0) = S_{w,0}(x)$

## Граничные условия

- **Непроницаемые границы:** $\mathbf{u}_\alpha \cdot \mathbf{n} = 0$ на внешних границах пласта
- **Скважины:** задаются через источниковые члены $q_\alpha$ с условием либо на дебит, либо на забойное давление
