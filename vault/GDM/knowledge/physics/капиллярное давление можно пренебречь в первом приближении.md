# Капиллярное давление можно пренебречь в первом приближении

## Определение

Капиллярное давление — скачок давления между фазами на границе раздела:

$$p_c(s_w) = p_o - p_w$$

## Обоснование пренебрежения

Оба документа проекта (Equations_07292020 и Equations_11222021) явно принимают:

> «Пренебрегая далее влиянием капиллярных эффектов, примем, что $p_o = p_w = p$»

При $p_c = 0$ давление обеих фаз совпадает. Это допустимо когда:
- Перепады давления в пласте $\Delta P \gg p_c$ — типично для задач промышленного вытеснения
- Нет тонких переходных зон между фазами

## Когда пренебрежение некорректно

- Тонкие пласты с выраженной переходной зоной
- Капиллярные концевые эффекты (capillary end effects) в лабораторных кернах
- Задачи с доминированием капиллярных сил ($N_{ca} \ll 1$)
- Модели с гравитационно-капиллярным равновесием

## Решение для GDM

Сначала реализуем без $p_c$ (как в документации). Это упрощает систему: одно давление $p$ для обеих фаз. Позже $p_c(s_w)$ можно добавить как опцию — потребует:
- Модификации уравнения давления (появляется дополнительный член с $\nabla p_c$)
- Отдельного вычисления $p_o$ и $p_w$
- Параметризации $p_c(s_w)$ (например, модель Брукса–Кори)
