# VAL-010: неактивная граничная (угловая) ячейка

**Подтип:** инвариантный (self-consistency).

**Проверяем:** деактивация единичных ячеек на границе сетки (углы — 2 соседа, борта — 3 соседа) не вызывает краш, сохраняет начальные условия в деактивированных ячейках и не влияет на динамику в дальних ячейках.

## Сценарии

1. **Corner cell (0,0) inactive** — угловая ячейка деактивирована, инжектор в центре 7x7 сетки. Проверка: P и Sw в деактивированной ячейке = init (epsilon 1e-12), P и Sw в дальних ячейках (i>2, j>2) совпадают с full-grid reference (epsilon 1e-4).

2. **Edge cell (i=0, j=mid) inactive** — бортовая ячейка деактивирована. Проверка аналогична, дальние ячейки: i >= 3.

3. **All four corners inactive** — одновременная деактивация 4 угловых ячеек. Проверка: init conditions + целостность графа связности (ConvertGlobal2Local < 0 для углов, все рёбра графа ведут к активным ячейкам).

4. **CSV export** ([.visual]) — overlay full-grid vs corner-off + карта разности ΔP, ΔSw. Python-скрипт: `scripts/plot_val010.py`.

## Результат

Все 3 количественных теста пройдены. Деактивация граничных ячеек корректно обрабатывается `SetConnectivityGraph_3D`. Граф связности не содержит ссылок на деактивированные ячейки. Начальные условия сохраняются через механизм `operator[](ptrdiff_t)` → `CellsInactive`.
