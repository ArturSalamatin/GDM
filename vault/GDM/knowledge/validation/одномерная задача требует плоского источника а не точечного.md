# Одномерная задача требует плоского источника а не точечного

## Суть

1D Buckley–Leverett в декартовых координатах — это течение от **плоского источника** (бесконечная плоскость x=0, однородный поток вдоль x). Скорость Дарси v = Q/A = const по всему сечению.

Формула Писмана моделирует **точечный источник** с радиальным притоком: `Q = 2πkh/ln(r_app/r_well) · λ_t · (P_res - P_well)`. Это принципиально другая геометрия.

## Следствия для GDM

GDM поддерживает только скважины с формулой Писмана. При попытке поставить 1D BL-задачу:

1. **Фронт не движется.** PI Писмана создаёт радиальный приток в одну ячейку, но межъячеечная проводимость T = A/Δx · λ_t слишком мала для передачи потока дальше. Вода накапливается в скважинной ячейке (Sw → 0.8–0.9), а в соседних Sw ≈ Sw_init
2. **Grid-dependence.** PI зависит от hx через r_app = 0.2·hx, что нарушает сеточную независимость — фундаментальное требование для теста сходимости
3. **Два фронта вместо одного.** PROD тоже точечный — создаёт свой радиальный отток, генерируя второй фронт у x=Lx

## Что нужно для корректной 1D валидации

Граничное условие на грани ячейки (flux BC): заданный поток Q через левую грань (INJ) и правую грань (PROD). Без формулы Писмана, без r_well, без r_app.

Это новый функционал — [[планируемые фичи|FEAT]].

## Диагностика (2026-07-21)

Параметры тестового сценария: Lx=100, hy=hz=1, k=100 мД, Q_inj=1000 кг/день.

- PI_well ≈ 9e-6 м³/(Па·день) — в 18 раз больше T_cell ≈ 5e-7
- dP_well ≈ 0.001 атм при Q=1 м³/день
- Межъячеечный поток ≈ 0.056 л/день из 1000 кг/день входящих
- Sw[0] = 0.82, Sw[1] = 0.32, Sw[2] ≈ 0.2 после t=5 дней

Увеличение сечения (hy, hz) при пропорциональном увеличении дебита не помогает — v = Q/A не меняется.

## Решение: радиальная постановка

Вместо 1D декартовой → 2D с одной INJ в центре и давлением на контуре питания (P = P_init). Формула Писмана корректна для точечного источника с радиальным притоком. Фронт расширяется как окружность.

Подтверждено 2026-07-21: сетка 41×41, Lx=Ly=200 м, Q_water = 50 м³/день, t=100 дней. Фронт на r ≈ 50 м, симметрия Sw_east = Sw_north идеальная.
