# Задача Бакли–Леверетта — аналитический тест для одномерного вытеснения

## Постановка

- 1D область (трубка тока), два несжимаемых несмешивающихся флюида
- Без капиллярного давления ($p_c = 0$)
- Без гравитации ($g = 0$)
- На входе — чистая вода, на выходе — свободный поток

## Функция фракционного потока

Доля воды в суммарном потоке:

$$f_w(s_w) = \frac{\sigma_w}{\sigma_w + \sigma_o} = \frac{k_{rw}/\mu_w}{k_{rw}/\mu_w + k_{ro}/\mu_o}$$

В документации (Equations_07292020, раздел «Задание граничных условий»):

> «Этот коэффициент имеет такой же смысл, что и функция Баклея–Леверетта для объёмных расходов»

## Аналитическое решение

Характеристическая скорость:

$$\frac{dx}{dt} = \frac{u_t}{m} \frac{df_w}{ds_w}$$

Профиль насыщенности $s_w(x, t)$ определяется веером характеристик.

### Скорость фронта — условие Ренкина–Гюгонио

Разрыв насыщенности (фронт вытеснения) движется со скоростью:

$$D = \frac{u_t}{m} \cdot \frac{f_w(s_w^+) - f_w(s_w^-)}{s_w^+ - s_w^-}$$

Положение фронта определяется касательной к кривой $f_w(s_w)$ из точки $(s_{wc}, 0)$.

## Критерии валидации для GDM

1. **Профиль насыщенности** — совпадение численного решения с аналитической кривой $s_w(x, t)$
2. **Скорость фронта** — положение разрыва в зависимости от времени
3. **Сходимость по сетке** — уменьшение ошибки при измельчении $h$
4. **Баланс массы** — суммарный расход фаз на входе/выходе должен совпадать с изменением насыщенности в области

## Ограничения теста

- Только 1D — не тестирует 2D/3D эффекты
- Без гравитации — не тестирует гравитационное растекание
- Без скважин — скважинная модель тестируется отдельно
- Явные схемы дают численную диффузию на фронте, неявные — тоже, но меньше при достаточном числе ячеек
