# Five-spot сравнение с MRST

## Параметры сценария

| Параметр | Значение |
|---|---|
| Сетка | 21×21×1 |
| Размер | 500×500×10 м |
| k | 100 мД |
| φ | 0.2 |
| μ_w / μ_o | 2.0 / 4.3 мПа·с |
| ρ_w / ρ_o | 1000 / 800 кг/м³ |
| k_rw / k_ro | S_w³ / (1-S_w)³ (Corey n=3) |
| P_init | 200 атм |
| S_w_init | 0 |
| T | 500 дней |

## Скважины

- INJ: центр (10,10), закачка воды 50 м³/день
- P1..P4: углы, добыча нефти 12.5 м³/день каждый

## Статус GDM

Тест `test_five_spot.cpp` проходит в Release (~26 сек). Newton сходится, 4-кратная симметрия подтверждена, bounds выполняются. Однако в Debug тест не укладывается в 60 сек из-за amgcl.

## Статус MRST

MATLAB-скрипт `MatLab/test_five_spot_mrst.m` подготовлен (шаблон). Требуется ручной запуск с установленным MRST.

## Сравнение

Скрипт `MatLab/compare_gdm_mrst.m` читает CSV обоих симуляторов, строит карты бок-о-бок, считает L2-ошибку. GDM-сторона записи через тег `[.export]` (скрытый тест).
