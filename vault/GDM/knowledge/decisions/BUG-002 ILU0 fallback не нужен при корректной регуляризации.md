# BUG-002 ILU0 fallback не нужен при корректной регуляризации

## Контекст

BUG-002 описывал zero pivot в ILU0 (`precondition(!math::is_zero((*D)[i]), "Zero pivot in ILU")`) при скалярном CPR на двухфазном Якобиане с Sw=0. Исходный workaround:
```cpp
if (math::is_zero((*D)[i])) (*D)[i] = math::identity<value_type>();  // fallback d=1
```

## Решение: убрать fallback

Экспериментально верифицировано 2026-07-13:

1. Вернули ilu0.hpp к upstream (строгий `precondition`)
2. Регуляризация в LinearProblem.cpp покрывает **все** строки Якобиана (`for i = 0..rhsSize`)
3. Тест Sw=0 пройден (4.53 сек), zero pivot не возникает
4. Все 296/296 тестов зелёные

## Обоснование

- Регуляризация в LinearProblem работает на уровне задачи: ставит `1e-6` на диагональ вырожденных строк **до** передачи матрицы в amgcl
- ILU0 получает матрицу с ненулевыми диагоналями → zero pivot невозможен
- Fallback внутри ILU0 маскировал бы проблему: если бы регуляризация пропустила строку, ILU0 молча подставил бы 1 — результат непредсказуемый

## Статус

- ilu0.hpp = upstream (без патчей GDM)
- cpr.hpp = GDM fork (true_impes_weights)
- LinearProblem.cpp = регуляризация всех строк
