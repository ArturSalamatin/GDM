# Команда /issue для создания GitHub issues

## Назначение

Автоматическое создание GitHub issue из записи в vault или свободного текста. Полный цикл: анализ кода → формирование issue → обратные ссылки.

## Расположение

`.claude/commands/issue.md`

## Режимы

| Режим | Пример | Что делает |
|---|---|---|
| **existing** | `/issue BUG-001` | Находит запись в vault, анализирует код, создаёт issue |
| **new** | `/issue описание` | Присваивает ID, создаёт запись в vault и issue |
| **dry-run** | `/issue --dry BUG-002` | Preview без создания |

## Ключевые возможности

- Проверка дубликатов через `gh issue list --search`
- Авто-labels по статусу: 🔴→critical, 🟡→workaround, Блокирует→blocking
- Валидация файлов и строк из vault-заметки
- Связывание issues через wiki-ссылки
- Обратные ссылки: GitHub → vault, vault → GitHub
- Предложение рабочей ветки: `fix/bug-001/<slug>`, `refactor/debt-007/<slug>`, `feat/feat-001/<slug>`, `val/val-001/<slug>`, `research/res-001/<slug>`
