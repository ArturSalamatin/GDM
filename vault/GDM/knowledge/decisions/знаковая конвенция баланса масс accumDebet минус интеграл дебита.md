# Знаковая конвенция баланса масс: accumDebet = −∫(Debit·dt)

## Тождество

```
ΔM + outflux − debet_accum = 0
```

Где:
- `ΔM = accumOil` или `accumWater` — кумулятивное изменение массы в пласте (+ = прибыло, − = убыло)
- `outflux = accumOilOutFlux` или `accumWaterOutFlux` — кумулятивный массовый поток через открытую границу (+ = утекло из пласта)
- `debet_accum = accumDebet` или `accumWaterDebet` — вычисляется как `−= Debit·τ` в [[MassBalance]], где `Debit > 0` = добыча, `< 0` = закачка

## Почему не `ΔM + outflux + debet_accum = 0`

`accumDebet` хранит `−∫(Debit·dt)`, а не `+∫(Debit·dt)`. Для добычи (`Debit > 0`) `accumDebet < 0`. Поэтому в тождестве баланса используется знак минус.

Для случая без скважин (`accumDebet = 0`) обе формулы эквивалентны — баг не проявляется.

## Контекст

Обнаружено при реализации водного баланса в [[2026-06-17 визуальная верификация single injector]]. Нефтяной баланс ранее проверялся только без нефтяных скважин, поэтому ошибка была скрыта.
