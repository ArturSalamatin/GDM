# Капиллярное давление отброшено и давление единое для обеих фаз

## Решение

Оба документа Equations явно принимают: $p_c = 0$, то есть $p_o = p_w = p$. В системе одно поле давления.

## Почему

- В задачах промышленного вытеснения перепады давления в пласте $\Delta P \gg p_c$
- Упрощает систему: вместо двух давлений ($p_o$, $p_w$) — одно $p$
- Убирает необходимость параметризации $p_c(s_w)$

## Следствия

- Уравнение давления — одно эллиптическое уравнение с коэффициентом $\sigma_t(s)$
- Насыщенность транспортируется без капиллярной диффузии — фронт вытеснения резкий
- Задача Бакли–Леверетта ($p_c = 0$) становится точным аналитическим тестом

## Когда нужно будет пересмотреть

- Моделирование переходных зон между пластами
- Капиллярные концевые эффекты
- Задачи с доминированием капиллярных сил ($N_{ca} \ll 1$)
