# Два режима скважин — фиксированное давление и фиксированный дебит

## Решение

Скважины реализуются двумя классами:
- `WellFixedPressure` — задано забойное давление, дебит вычисляется из формулы Дюпюи
- `WellFixedProduction` — задан дебит (отбор/закачка), забойное давление вычисляется

## Переключение режимов во времени

Из документации (ReservoirSimulator_01052021):

Для каждого временного интервала скважине задаются три вектора: `productions_`, `injections`, `P_`. Режим определяется автоматически:
- Если `productions_[t] > 0` — режим отбора (фиксированный дебит)
- Если `injections[t] > 0` — режим закачки (фиксированный дебит)
- Если `P_[t] > 0` — режим фиксированного давления
- В режиме фиксированного давления значения `productions_` и `injections` игнорируются, и наоборот

Единицы: отбор/закачка — м³/сутки.

## Параметры скважины

- `localPosIdx` — индексы ячеек, вскрытых скважиной (в линейной нумерации $l$)
- `perfLength` — длина перфорации в каждой ячейке, м
- `wellR` — радиус скважины, м
- `equivR` — эквивалентный радиус ячейки (вычисляется из $h_x$, $h_y$)
- `startTime` — момент ввода скважины в эксплуатацию (по умолчанию $t = 0$)

## Добавление скважин

Через методы `ReservoirSimulator`:
- `AddWell_FixedPressure(X_cellIdx, Y_cellIdx, Z_cellIdx, ...)`
- `AddWell_FixedProduction(X_cellIdx, Y_cellIdx, Z_cellIdx, ...)`

Координаты скважины задаются индексами ячеек $(i, j, k)$, которые внутри преобразуются в линейный индекс $l$.
