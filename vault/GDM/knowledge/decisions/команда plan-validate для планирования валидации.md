# Команда /plan-validate для планирования валидации

## Назначение

Построение детализированного плана валидационного кейса: сравнение GDM с аналитикой, MRST, ECLIPSE или инвариантной проверкой.

## Расположение

`.claude/commands/plan-validate.md`

## Аргумент

`VAL-NNN` или номер GitHub issue.

## Подтипы

| Подтип | Пример |
|---|---|
| **Аналитический** | VAL-001: Buckley–Leverett 1D |
| **Сетчатая сходимость** | VAL-002: h-refinement |
| **Межсимуляторный** | VAL-003: five-spot vs MRST |
| **Инвариантный** | VAL-006: баланс масс |

## Ключевые отличия от других plan-команд

- Ничего не меняется в ядре симулятора (только тесты и скрипты)
- Ключевой артефакт — эталонное решение (формулы, код Python, таблица)
- Метрики с tolerance — количественная, не только визуальная проверка
- Визуальная верификация обязательна (overlay plots)
