# Upstream-взвешивание для доли фазы и гармоническое среднее проницаемости на гранях

## Решение

При вычислении потока через грань между ячейками $l$ и $l'$:
- **Доля фазы $f_c$** берётся из ячейки с бо́льшим давлением (upstream, «против потока»)
- **Суммарная подвижность $\sigma_t$** на грани вычисляется через **среднее гармоническое** абсолютных проницаемостей соседних ячеек

## Почему

### Upstream

Из документации (Equations_07292020):

> «Свойства полученной задачи требуют, чтобы на каждой грани доля фазы в потоке $f_c$ аппроксимировалась выражением "против потока"»

Upstream обеспечивает:
- Монотонность схемы (нет осцилляций насыщенности)
- Физичность: фаза «выносится» из ячейки, откуда жидкость вытекает

### Гармоническое среднее

Из документации:

> «Суммарная подвижность $\sigma_t$ должна аппроксимироваться через среднее обратных величин в соседних ячейках»

Гармоническое среднее корректно для последовательного расположения слоёв с разной проницаемостью (консервативная оценка).

## Учёт гравитации

Для гравитационного слагаемого upstream определяется отдельно: движущая сила направлена всегда вниз (по оси $z$), независимо от градиента давления.

## Граничные условия Дирихле

При задании давления $p_j$ на границе области: подвижность за границей считается бесконечной (коэффициент 2 включается в площадь грани). Если поток направлен из-за границы — затекает чистая вода ($f_w = 1$).
