# Команда /plan-research для планирования экспериментов

## Назначение

Построение детализированного плана численного эксперимента: проверка гипотезы, параметрическое исследование, сравнение альтернативных подходов.

## Расположение

`.claude/commands/plan-research.md`

## Аргумент

`RES-NNN` или номер GitHub issue.

## Ключевое отличие

Результат — **вывод** (подтвердить/отвергнуть гипотезу), а не код в main. Может привести к созданию FEAT или VAL, а может — к закрытию как ❌ ОТВЕРГНУТО.

## Подтипы

| Подтип | Пример |
|---|---|
| **Схема/метод** | RES-001: upstream vs TVD |
| **Параметрическое** | RES-004: PI-контроллер |
| **Архитектурное** | RES-002: IMPES vs FI |
| **Физический эффект** | RES-005: капиллярное давление |

## Фазы работы

1. **Сбор контекста** — vault, код, зависимости
2. **Проектирование** — гипотеза, дизайн, метрики, мат. обоснование
3. **Детализация** — baseline → реализация → прогоны → анализ → вывод
4. **Верификация** — 3 раунда
5. **Сохранение** — план в vault, связи
