# Уравнение давления с несжимаемыми фазами даёт эллиптическую задачу

## Вывод уравнения для давления

Суммирование уравнений неразрывности по обеим фазам с учётом $s_o + s_w = 1$ и подстановкой закона Дарси при $p_c = 0$:

$$-\nabla \cdot \left(\sigma_t(s) \nabla p\right) + \nabla \cdot \left(\sigma_t(s) \bar{\rho} g \nabla z\right) = \sum_c q_c$$

где $\sigma_t = \sigma_o + \sigma_w$ — суммарная подвижность, зависящая от насыщенности.

Это эллиптическое уравнение: при фиксированном поле $s$ коэффициент $\sigma_t(s)$ известен, и задача — линейная относительно $p$.

## Дискретизация — метод конечных объёмов

### Сетка

3D структурированная сетка с шагами $h_x$, $h_y$ (однородные в горизонтальной плоскости), $h_z$ (может меняться по слоям). Глобальная нумерация:

$$l = i + n_x j + n_x n_y k$$

### Поток через грань

Поток суммарной фазы через нижнюю грань ячейки $(i,j,k)$ и $(i,j,k-1)$:

$$F_{l,l'} = \sigma_t |_{l,l'} \cdot A_{l,l'} \cdot \frac{p_l - p_{l'}}{d_{l,l'}}$$

где:
- $\sigma_t|_{l,l'}$ — подвижность на грани (среднее гармоническое абсолютных проницаемостей × подвижность фаз)
- $A_{l,l'}$ — площадь грани (для граней ⊥ оси $z$: $h_x h_y$; для граней ⊥ плоскости $xy$: площадь с полусуммой высот смежных ячеек)
- $d_{l,l'}$ — расстояние между центрами ячеек

### Подвижность на грани

Доля фазы в потоке аппроксимируется **upstream** (против потока):
- Берётся значение $f_c$ из ячейки с бо́льшим давлением

Суммарная подвижность $\sigma_t$ на грани — через **среднее гармоническое** абсолютных проницаемостей соседних ячеек.

### Граничные условия

Три типа ГУ:
1. **Дирихле** (задано давление $p_j$ на границе) — модификация подвижности: «подвижность за границей устремляется к бесконечности» (коэффициент 2 в площади грани)
2. **Нейман** (задан поток через грань) — замена потока в уравнении
3. **Аквифер** (третьего рода) — комбинация давления и потока

При затекании из-за границы принимается чистая вода ($f_w = 1$).

## Результат дискретизации

Система линейных алгебраических уравнений $A \mathbf{p} = \mathbf{b}$ с разреженной матрицей. На равномерной сетке — пятиточечный (2D) или семиточечный (3D) шаблон.
