# Численные методы решения уравнений фильтрации

## IMPES — Implicit Pressure Explicit Saturation

Базовая схема расщепления: давление решается неявно, насыщенность — явно.

1. **Неявный шаг по давлению:** из уравнений неразрывности для суммарной фазы получается эллиптическое уравнение для давления. Решается на каждом временном шаге как СЛАУ.
2. **Явный шаг по насыщенности:** зная поле давления (и скоростей), обновляем насыщенность по явной схеме.

Преимущества: простота реализации, естественное разделение эллиптической и гиперболической частей.
Недостатки: ограничение по CFL на шаг по времени.

## Дискретизация давления

### Конечные объёмы / конечные разности

- Двухточечная аппроксимация потока (TPFA) на структурированной сетке
- Среднее гармоническое проницаемости на гранях ячеек
- Upstream-взвешивание подвижности на гранях

Результат — система линейных уравнений $A \mathbf{p} = \mathbf{b}$.

## Транспорт насыщенности

Явная схема первого порядка:

$$S_w^{n+1}_i = S_w^n_i + \frac{\Delta t}{\phi_i V_i} \sum_j F_{w,ij}^n + \frac{\Delta t}{\phi_i V_i} q_{w,i}$$

где $F_{w,ij}$ — поток воды через грань между ячейками $i$ и $j$.

### CFL-ограничение

$$\Delta t \leq \min_i \frac{\phi_i V_i}{\sum_j |F_{total,ij}| \cdot \max \left| \frac{df_w}{dS_w} \right|}$$

где $f_w$ — функция Бакли–Леверетта (доля воды в потоке).

## Линейные солверы для системы давления

- Прямые: разреженный LU (для малых задач / отладки)
- Итерационные: CG с предобуславливанием (ILU, AMG) для больших задач
- Библиотеки-кандидаты: Eigen, PETSc, Trilinos
