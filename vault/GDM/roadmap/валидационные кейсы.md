# Валидационные кейсы

Реестр задач по верификации и валидации симулятора. Каждый кейс — сравнение результатов GDM с аналитическим решением, другим симулятором (MRST, ECLIPSE) или экспериментальными данными. В отличие от BUG (сломанное), DEBT (улучшение кода), FEAT (новый функционал) — валидация ничего не меняет в коде, а доказывает корректность.

Связь с физикой: [[математическая модель двухфазной фильтрации]].

---

## 1D задачи

### VAL-001: Buckley–Leverett 1D
- **Эталон:** аналитическое решение (метод характеристик + условие Ренкина–Гюгонио)
- **Сценарий:** 1D вытеснение нефти водой, без капиллярки, без гравитации
- **Метрика:** положение фронта, профиль Sw(x,t), L2-норма ошибки
- **Зависимости:** BUG-001 (Newton divergence блокирует полный прогон)
- **Подробности:** [[задача Бакли-Леверетта — аналитический тест для одномерного вытеснения]]
- **GitHub:** [#15](https://github.com/ArturSalamatin/GDM/issues/15)
- **План:** [[val-001 buckley-leverett-1d]]
- **Ветка:** val/val-001/buckley-leverett-1d
- **Статус:** ✅ ПРОЙДЕН 2026-07-03 (L2 = 0.030 < 0.05, фронт ±1 ячейка, монотонность ОК)

### VAL-002: Сходимость на сетке (1D Buckley–Leverett)
- **Эталон:** тот же аналитический профиль
- **Сценарий:** серия сеток 21, 51, 101, 201 ячеек → L2-норма vs h
- **Метрика:** порядок сходимости (ожидание: ~1 для upstream, ~2 для TVD)
- **Зависимости:** VAL-001
- **Статус:** ⬜ НЕ НАЧАТО

## Неоднородность пластовых свойств

Все текущие тесты используют однородный пласт (`make_uniform_horizon`). Добавлено 2026-07-02.

### VAL-023: Контраст проницаемости (k₁=100 мД, k₂=1 мД)
- **Эталон:** self-consistency (замедление фронта на границе зон)
- **Сценарий:** две зоны: k₁=100 мД (INJ), k₂=1 мД (PROD). Однородная пористость
- **Метрика:** гармоническое среднее подвижности на границе зон, фронт замедляется, баланс массы
- **Приоритет:** высокий (скрывает баги в гармоническом среднем)
- **Статус:** ⬜ НЕ НАЧАТО

### VAL-024: Анизотропия проницаемости (perm_x ≠ perm_y)
- **Эталон:** self-consistency (вытянутый фронт)
- **Сценарий:** perm_x = 100 мД, perm_y = 10 мД. INJ в центре
- **Метрика:** Sw(±Δx) > Sw(±Δy) при одинаковом расстоянии от INJ, баланс массы
- **Приоритет:** средний
- **Статус:** ⬜ НЕ НАЧАТО

### VAL-025: Линза нулевой проницаемости (k=0, ячейки активны)
- **Эталон:** self-consistency (нет переноса через линзу)
- **Сценарий:** однородный пласт, блок 3×3 ячеек в центре имеет k=0. Ячейки активны (P и Sw определены)
- **Метрика:** подвижность = 0 → нет переноса через линзу, регрессия BUG-007
- **Приоритет:** высокий (регрессионный тест BUG-007)
- **Связано с:** [[bug-007 harmonic-mean-zero-division]]
- **Статус:** ⬜ НЕ НАЧАТО

### VAL-026: Неоднородная пористость (φ₁=0.3, φ₂=0.05)
- **Эталон:** self-consistency (фронт быстрее в зоне малой пористости)
- **Сценарий:** две зоны с разной пористостью, одинаковая проницаемость. INJ на границе
- **Метрика:** Sw(φ₂) > Sw(φ₁) при одинаковом расстоянии от INJ, баланс массы

- **Статус:** ⬜ НЕ НАЧАТО

## Newton convergence / timestep control

### VAL-030: Newton 1 итерация при стационаре
- **Эталон:** аналитика (RHS = 0)
- **Сценарий:** uniform IC, нет скважин, closed boundary
- **Метрика:** Newton converges за 0–1 итерацию, P и Sw не меняются
- **Приоритет:** средний (регрессионный тест DEBT-047)
- **Связано с:** [[DEBT-047]]
- **Статус:** ⬜ НЕ НАЧАТО

### VAL-031: Wasted trial recovery (корректность rollback)
- **Эталон:** self-consistency (P, Sw возвращены к предыдущим после wasted trial)
- **Сценарий:** агрессивный начальный τ, сложный сценарий → принудить Newton к wasted trial
- **Метрика:** P и Sw после rollback = P и Sw до failed step, баланс массы
- **Приоритет:** средний
- **Статус:** ⬜ НЕ НАЧАТО

### VAL-032: Timestep growth после лёгкого шага
- **Эталон:** self-consistency
- **Сценарий:** один шаг с Newton=1 iter → следующий τ > предыдущего (при включённом PI-контроллере)
- **Метрика:** τ_{n+1} > τ_n
- **Зависимости:** DEBT-006 (PI-контроллер выключен)
- **Приоритет:** низкий
- **Статус:** ⬜ НЕ НАЧАТО

### VAL-039: PI-контроллер через breakthrough (1D + five-spot)
- **Эталон:** self-consistency + PI vs fixed-dt
- **Сценарий:** (a) BL 1D Nx=50, PI включён, до 1.5 PVI — фронт проходит продюсер; (b) five-spot 21×21, PI включён; (c) тот же 1D без PI — сравнение профилей Sw
- **Метрика:** Sw ∈ [0,1]; невязка баланса масс < 1e-6; WastedTrials < порога; симметрия five-spot (Δ < 1e-6); |Sw_PI − Sw_fixed| < ε; CSV-экспорт dt(t) и Sw(x) для визуальной верификации
- **Зависимости:** VAL-001 (BL-инфраструктура), VAL-032 (timestep growth)
- **Примечания:** dt-история в NumericalParameters + публичный геттер BalanceTracker() для точного баланса
- **План:** [[val-039 pi-controller-breakthrough]]
- **GitHub:** [#40](https://github.com/ArturSalamatin/GDM/issues/40)
- **Ветка:** `val/val-039/pi-controller-breakthrough`
- **Статус:** 🟢 ПОКРЫТ ТЕСТАМИ (2026-07-19)
