# Валидационные кейсы

Реестр задач по верификации и валидации симулятора. Каждый кейс — сравнение результатов GDM с аналитическим решением, другим симулятором (MRST, ECLIPSE) или экспериментальными данными. В отличие от BUG (сломанное), DEBT (улучшение кода), FEAT (новый функционал) — валидация ничего не меняет в коде, а доказывает корректность.

Связь с физикой: [[математическая модель двухфазной фильтрации]].

---

## 1D задачи

### VAL-001: Buckley–Leverett 1D
- **Эталон:** аналитическое решение (метод характеристик + условие Ренкина–Гюгонио)
- **Сценарий:** 1D вытеснение нефти водой, без капиллярки, без гравитации
- **Метрика:** положение фронта, профиль Sw(x,t), L2-норма ошибки
- **Зависимости:** BUG-001 (Newton divergence блокирует полный прогон)
- **Подробности:** [[задача Бакли-Леверетта — аналитический тест для одномерного вытеснения]]
- **Статус:** 🔴 ЗАБЛОКИРОВАН (BUG-001)

### VAL-002: Сходимость на сетке (1D Buckley–Leverett)
- **Эталон:** тот же аналитический профиль
- **Сценарий:** серия сеток 21, 51, 101, 201 ячеек → L2-норма vs h
- **Метрика:** порядок сходимости (ожидание: ~1 для upstream, ~2 для TVD)
- **Зависимости:** VAL-001
- **Статус:** ⬜ НЕ НАЧАТО

## 2D задачи

### VAL-003: Five-spot GDM vs MRST
- **Эталон:** MRST (incomp + incompTPFA)
- **Сценарий:** 21×21×1, одна INJ + одна PROD, однородный пласт
- **Метрика:** карта давления, карта Sw, время прорыва, cumulative oil production
- **Подробности:** [[five-spot сравнение с MRST]]
- **Статус:** 🟡 ЧАСТИЧНО (давление совпадает, Sw визуально, количественно не проверено)

### VAL-004: Five-spot сетчатая сходимость
- **Эталон:** fine-grid self-convergence (101×101 vs 21×21, 51×51)
- **Сценарий:** тот же five-spot, серия сеток
- **Метрика:** L2-норма разности Sw, порядок сходимости
- **Зависимости:** VAL-003
- **Статус:** ⬜ НЕ НАЧАТО

## 3D задачи

### VAL-005: Многопластовый сценарий
- **Эталон:** MRST или послойное сравнение с 2D
- **Сценарий:** 3D сетка с несколькими пластами, вертикальные скважины
- **Метрика:** давление и Sw по слоям
- **Зависимости:** текущая модель не имеет вертикальных перетоков ([[вертикальные перетоки исключены из модели]])
- **Статус:** ⬜ НЕ НАЧАТО

## Баланс масс

### VAL-006: Глобальный баланс масс
- **Эталон:** аналитический (∑Q_inj·dt = ΔV_water в пласте + ∑Q_prod·dt)
- **Сценарий:** любой сценарий с INJ+PROD
- **Метрика:** относительная невязка < 1e-10
- **Подробности:** [[знаковая конвенция баланса масс accumDebet минус интеграл дебита]]
- **Статус:** 🟢 ПОКРЫТ ТЕСТАМИ (test_balance.cpp)

## Как добавить кейс

Формат записи:
```
### VAL-NNN: <название>
- **Эталон:** <с чем сравниваем — аналитика / MRST / ECLIPSE / эксперимент>
- **Сценарий:** <сетка, условия, параметры>
- **Метрика:** <что измеряем, tolerance>
- **Зависимости:** VAL-NNN / BUG-NNN / FEAT-NNN (если есть)
- **Подробности:** [[wiki-ссылка]] (если есть заметка)
- **GitHub:** [#N](url) (после создания issue)
- **План:** [[имя плана]] (после /plan-validate)
- **Статус:** ⬜ НЕ НАЧАТО | 🔴 ЗАБЛОКИРОВАН | 🟡 ЧАСТИЧНО | 🟢 ПОКРЫТ ТЕСТАМИ
```
