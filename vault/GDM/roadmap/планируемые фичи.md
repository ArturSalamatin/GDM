# Планируемые фичи

Реестр новых функциональных возможностей. Каждая фича — расширение модели, нового функционала или нового режима работы. В отличие от BUG (сломанное поведение) и DEBT (работающий код, который нужно улучшить), фичи — это то, чего ещё нет.

Фичи привязаны к фазам [[roadmap долгосрочный план развития GDM]].

## Фаза 3: Стабилизация ядра

### FEAT-010: Threshold-based fallback в CPR block-LU (уровень 2)
- **Суть:** заменить exact-zero проверку `math::is_zero(d)` в `cpr.hpp:invert()` на threshold-based: `|d| < τ·max(|A_row|)`. При срабатывании — подставить weight = (1, 0) напрямую (минуя обратный ход с испорченной LU-факторизацией). Покрывает near-zero pivots, которые уровень 1 (BUG-002) пропускает
- **Физика:** near-zero pivot возникает при Sw близком к нулю (не точно нуль) — производные ОФП dkrw/dSw = n·Sw^(n-1) → 0, строка Якобиана водной фазы near-singular. На тонких сетках ILU elimination может уменьшить pivot до 1e-15, что формально не zero, но вызывает overflow при LU-разложении → weights ≈ (0, 0) → строка App ≈ 0 → AMG получает near-singular pressure matrix
- **Зависимости:** BUG-002 (уровень 1 — exact zero fallback, должен быть реализован первым)
- **Контроль:** при τ = 0 поведение = уровень 1; все существующие тесты зелёные; Grid convergence 41×41 — число GMRES-итераций не увеличилось
- **Тесты:** (1) тест с Sw_init = 0.01 на тонкой сетке (61×61) — near-zero провоцируется; (2) сравнение числа GMRES-итераций до/после; (3) regression на полном наборе
- **Подробности:** [[zero pivot в ILU0 при скалярном CPR на двухфазном Якобиане]]
- **GitHub:** [#21](https://github.com/ArturSalamatin/GDM/issues/21)
- **План:** [[feat-010 cpr-threshold-fallback]]
- **Ветка:** feat/feat-010/cpr-threshold-fallback
- **Фаза:** 3
- **Статус:** ⬜ НЕ НАЧАТО

### FEAT-011: True-IMPES / ABF weights для CPR decoupling (уровень 3)
- **Суть:** заменить наивное обращение диагональных блоков Якобиана (`invert()`) на вычисление True-IMPES weights из nullspace столбца ∂F/∂Sw. Weights w = (∂F_water/∂Sw, −∂F_oil/∂Sw) с нормировкой. При полностью вырожденном блоке (оба элемента = 0) — w = (1, 0), что корректно (давление decoupled тривиально). Устраняет проблему singular/near-singular blocks принципиально, без fallback'ов
- **Физика:** CPR (Constrained Pressure Residual) строит скалярную pressure-pressure подматрицу App ≈ Шур-дополнение Kpp − Kps·Kss⁻¹·Ksp. Текущий amgcl использует quasi-IMPES decoupling через `invert()` (первый столбец A⁻¹). True-IMPES (Wallis 1983, Cao et al. 2005) вычисляет weights w из условия wᵀ·∂F/∂Sw = 0 — требует только столбец ∂F/∂Sw, не полный блок. Для B=2 это решается аналитически. При Sw → 0 отношение ∂Fw/∂Sw к ∂Fo/∂Sw остаётся определённым (через отношение подвижностей), даже когда абсолютные значения → 0. Обращение матрицы не нужно
- **Зависимости:** FEAT-010 (уровень 2 — промежуточный шаг, позволяет верифицировать near-zero handling до принципиальной замены)
- **Контроль:** (1) backward compat: при одинаковых условиях (невырожденные блоки) App совпадает с точностью round-off; (2) все тесты зелёные; (3) Grid convergence: число GMRES-итераций ≤ текущего (должно уменьшиться на тонких сетках)
- **Тесты:** (1) unit-тест: вычисление weights для known 2×2 блоков (невырожденный, near-singular, fully singular); (2) unit-тест: App строка для невырожденного блока совпадает с `invert()`-based; (3) regression + Grid convergence; (4) тест Sw_init = 0.0 (five-spot) — должен работать без обхода Sw_init = 0.001
- **Литература:** Wallis J.R. (1983) *Incomplete Gaussian Elimination as a Preconditioning for Generalized Conjugate Gradient Acceleration*, SPE 12265. Cao H. et al. (2005) *A General Framework for CPR Preconditioners*, SPE 96030. Saad Y. (2003) *Iterative Methods for Sparse Linear Systems*, sec. 10.3.4
- **PR в amgcl:** после реализации и верификации — оформить pull request в upstream amgcl (Denis Demidov). Включает: True-IMPES weights как опция `prm.weights_type = "true_impes"` (default = текущее поведение `"quasi_impes"` для backward compat). Мотивация для автора: несжимаемые фазы без капиллярного давления — легитимный use case, singular blocks ожидаемы
- **Подробности:** [[zero pivot в ILU0 при скалярном CPR на двухфазном Якобиане]]
- **Фаза:** 3
- **Статус:** ⬜ НЕ НАЧАТО

## Фаза 4: Расширение модели скважин

### FEAT-001: Режим фиксированного забойного давления (BHP)
- **Суть:** скважина работает при заданном P_wf, дебит определяется формулой Писмана
- **Физика:** Q = WI · λ_t · (P_cell - P_wf), знак определяет инжектор/продюсер
- **Зависимости:** FEAT-002 (Peaceman WI)
- **Тесты:** одна скважина BHP, five-spot BHP, переключение дебит↔BHP mid-simulation
- **Фаза:** 4.1
- **Статус:** ⬜ НЕ НАЧАТО

### FEAT-002: Модель Peaceman (productivity index)
- **Суть:** WI = 2πkh / (ln(r_e/r_w) + S), с анизотропной поправкой r_0
- **Физика:** r_0 = 0.28·√(√(ky/kx)·Δx² + √(kx/ky)·Δy²) / (⁴√(ky/kx) + ⁴√(kx/ky))
- **Тесты:** сравнение P_wf с аналитикой, сетчатая сходимость WI
- **Фаза:** 4.2
- **Статус:** ⬜ НЕ НАЧАТО

### FEAT-003: Закрытые границы (no-flow BC)
- **Суть:** корректная работа без открытых граней, регуляризация давления
- **Физика:** Σ Q_inj = Σ Q_prod (баланс масс замкнутой системы), pin-pressure или средневзвешенное
- **Зависимости:** FEAT-001 (BHP нужен для замкнутого пласта)
- **Тесты:** замкнутый пласт INJ+PROD, баланс масс, P не дрейфует
- **Подробности:** [[закрытые границы требуют корректной регуляризации давления]]
- **Фаза:** 4.3
- **Статус:** ⬜ НЕ НАЧАТО

## Фаза 5: Расширение физики

### FEAT-004: Слабая сжимаемость фаз
- **Суть:** линейная EOS: ρ = ρ_ref(1 + c_f(P - P_ref)), сжимаемость породы c_r
- **Физика:** добавляет аккумуляционный член ∂(φρ)/∂t, уравнение давления становится параболическим
- **Контроль:** при c_f = c_r = 0 результат совпадает с несжимаемым
- **Фаза:** 5.1
- **Статус:** ⬜ НЕ НАЧАТО

### FEAT-005: Капиллярное давление
- **Суть:** P_cow(S_w) — функция Леверетта или табличная
- **Физика:** P_o = P_w + P_cow, влияет на уравнение давления и транспорт
- **Контроль:** при P_cow = 0 результат совпадает с текущей моделью
- **Подробности:** [[капиллярное давление можно пренебречь в первом приближении]]
- **Фаза:** 5.2
- **Статус:** ⬜ НЕ НАЧАТО

### FEAT-006: Гравитация
- **Суть:** гравитационный член ∇·(λ_α ρ_α g ∇z) в уравнении потока
- **Физика:** существенен для 3D задач с разницей глубин
- **Контроль:** при горизонтальном пласте результаты не меняются
- **Фаза:** 5.3
- **Статус:** ⬜ НЕ НАЧАТО

## Как добавить фичу

Формат записи:
```
### FEAT-NNN: <название>
- **Суть:** что именно добавляется
- **Физика:** уравнения, модель (если применимо)
- **Зависимости:** FEAT-NNN / BUG-NNN (если есть)
- **Контроль:** backward compatibility check
- **Тесты:** что проверять
- **Подробности:** [[wiki-ссылка]] (если есть заметка)
- **GitHub:** [#N](url) (после создания issue)
- **План:** [[имя плана]] (после /plan-feature)
- **Фаза:** N.M (ссылка на roadmap)
- **Статус:** ⬜ НЕ НАЧАТО | 🔧 В РАБОТЕ | ✅ ГОТОВО
```
