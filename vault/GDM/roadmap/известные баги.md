### BUG-001: SIGSEGV при закачке воды — out-of-bounds в AddFlowFieldSnapShot при ny=1
- **Симптом:** SIGSEGV (access violation) после первого успешного временного шага при сетке с ny=1
- **Причина:** `OverallFluxes()` не заполняет `j_Y` при `ny <= 1`, но `AddFlowFieldSnapShot()` безусловно обращается к `j_Y[k]` → out-of-bounds. Исходный диагноз (NaN в SetRefWellPressure) **опровергнут** — Newton сходится нормально
- **Воспроизведение:** тест `[.wells]` в test_buckley_leverett.cpp (сетка 10×1×1)
- **Блокирует:** Buckley–Leverett симуляция vs аналитика, любые сценарии с ny=1 или nx=1
- **Статус:** ✅ ИСПРАВЛЕНО 2026-06-28
- **GitHub:** [#1](https://github.com/ArturSalamatin/GDM/issues/1)
- **План:** [[bug-001 well-state-rollback]]
- **Ветка:** fix/bug-001/well-state-rollback
- **Подробности:** [[Newton divergence при закачке воды через скважину]]

### BUG-002: CPR zero pivot — три проявления
- **Симптом:** солвер не сходится или abort() в Debug при определённых конфигурациях сетки/насыщенности
- **Проявление 1 (ILU0):** zero pivot в `ilu0.hpp:156` при тонкой сетке (41×41) даже при Sw=0.2 — elimination обнуляет pivot. Обход: fallback `D[i]=1` (наш патч в ilu0.hpp)
- **Проявление 2 (CPR block inversion):** при Sw=0 вся Sw-строка Якобиана нулевая → CPR 2×2 block inversion singular → NaN → GMRES diverges. Обход: Sw_init ≥ 0.001
- **Проявление 3 (CPR block-LU, `cpr.hpp:522`):** `assert(!math::is_zero(d))` в LU-факторизации B×B блока внутри CPR. Падает в обоих конфигах (Release и Debug) — abort(). Тест: `Grid convergence: single injector` (278/279 passed, 1 failed). Обнаружено 2026-06-29 при верификации BUG-001. Не покрывается патчем ilu0.hpp
- **Причина (общая):** near-singular или singular блоки Якобиана при определённых Sw → zero pivot на разных уровнях CPR-прекондиционера (ILU0, block inversion, block-LU)
- **Обход:** Sw_init = 0.001 вместо 0.0 (не устраняет проявление 3)
- **Статус:** ✅ ИСПРАВЛЕНО 2026-06-29 — все три проявления покрыты (ilu0 fallback, Sw_init ≥ 0.001, cpr.hpp fallback). Near-zero pivot → FEAT-010
- **GitHub:** [#4](https://github.com/ArturSalamatin/GDM/issues/4)
- **Ветка:** fix/bug-002/cpr-zero-pivot
- **План:** [[bug-002 cpr-zero-pivot]]
- **Подробности:** [[zero pivot в ILU0 при скалярном CPR на двухфазном Якобиане]]

### BUG-020: несогласованность единиц массового и объёмного расхода в формуле Писмана
- **Симптом:** эффективный расход qt_eff ≈ 0.0036 м/день при номинальном Q_water = 1000 кг/день (ожидание 1 м³/день → qt = 1 м/день). Расхождение в ~280 раз
- **Причина:** `SetRefWellPressure` складывает `CurOverallDebit()` (кг/день из MER) с `factor·λ·P_res` (м³/день). Формула `P_well = (-Q + Σ PI·λ·P_res) / (Σ PI·λ)` корректна только если Q и PI·λ·ΔP в одних единицах
- **Решение:** ввести ρ_mix в SetRefWellPressure, ρ_oil/ρ_water в rhs и якобиан, согласовать BalanceOil и CurOilDebit_Num/CurWaterDebit_Num
- **Файл:** `HydroSolver/Reservoir/Well/Wells.cpp`, `HydroSolver/Reservoir/Well/SomeWell.cpp`, `HydroSolver/Reservoir/Well/SomeWell.h`
- **Статус:** ✅ исправлено 2026-07-07
- **GitHub:** [#16](https://github.com/ArturSalamatin/GDM/issues/16)
- **Ветка:** fix/bug-020/debit-unit-conversion
- **Обнаружено при:** анализе VAL-001
- **Подробности:** [[BUG-020 несогласованность единиц расхода в формуле Писмана]]
- **План:** [[bug-020 debit-unit-conversion]]

### BUG-022: `LowerPointNonUniformMesh` — `return NAN` из функции с возвратом `int` (UB)
- **Симптом:** MSVC C4244 warning на строках 56, 62, 64 файла `MathRoutines.cpp`. Строка 62 — undefined behavior: `return NAN` (double) из функции `int LowerPointNonUniformMesh()`
- **Причина:** функция объявлена как `int`, но использует `return NAN` для сигнализации «точка вне сетки». По стандарту C++ (§7.3.10) преобразование NaN → int — UB. На MSVC результат — произвольное значение `int`, которое далее используется как индекс массива в `SomeFlowField::operator()` (строка 68) → out-of-bounds доступ
- **Файл:** `HydroSolver/Solver/Math/MathRoutines.cpp:56,62,64`, `MathRoutines.h:50,52`
- **Затрагивает также:** `SomeFlowField.cpp:68` — call site, где результат используется как индекс без проверки на ошибку
- **Дополнительно:** строка 56 (`LowerPointUniformMesh`) — `std::floor()` возвращает `double`, усечение в `int` (C4244); строка 64 — `std::distance()` возвращает `ptrdiff_t`, усечение в `int` (C4244)
- **Воспроизведение:** `cmake --build build --config Release` — видны C4244 warnings. Вызов `LowerPointNonUniformMesh` с `queryX` вне диапазона сетки → UB
- **GitHub:** [#32](https://github.com/ArturSalamatin/GDM/issues/32)
- **План:** [[bug-022 mathroutines-nan-ub]]
- **Ветка:** fix/bug-022/mathroutines-nan-ub
- **Статус:** 🔴 ОТКРЫТ (UB при runtime, не просто warning)
