# 2026-06-17 — Исследование закрытых границ и pin pressure

## Задача
Создать тестовый сценарий: 2 скважины (INJ + PROD), закрытая граница (no-flow), фиксированный дебит. Режим BHP (заданное забойное давление) отложен — не реализован в симуляторе.

## Фундаментальная проблема
Несжимаемые фазы + закрытая граница → давление определено с точностью до константы → ядро матрицы содержит вектор `(0, 1, 0, 1, ..., 0, 1)` (постоянный сдвиг P) → AMG не сходится.

## Что пробовали

| Подход | AMG | Баланс масс | Почему не работает |
|---|---|---|---|
| eps=1e-12 на диагональ P (без RHS) | не сходится | точный | eps слишком мал для AMG |
| eps=1e-8 на диагональ P (без RHS) | не сходится | точный | `‖rhs‖ ≈ 0` → relative tolerance AMG не достижима |
| penalty ~1e-6 + RHS (все ячейки) | 0 rollback | oil: -2800 кг/100д | fictitious source `penalty·(P-Pref)` в каждой ячейке |
| penalty + RHS (только center cell) | 0 rollback | oil: -2800 кг/100д | P_center ≠ Pref из-за несимметричных подвижностей |
| penalty на диагональ без RHS (pin cell) | не сходится | — | δP не ограничена → UpdateGrid reject |
| hard pin: replace oil eq в cell 0 | 0 rollback | oil: -2812 кг, water: OK | oil eq удалено в pin cell → oil не консервируется |
| hard pin: replace water eq в cell 0 | 0 rollback | oil: OK, water: -3515 кг | water eq удалено → water не консервируется (0.014%) |

## Выводы

1. **Pin pressure — фиктивный источник/сток.** Любая форма pin pressure (penalty с RHS или жёсткая подстановка) нарушает conservation в pin cell. Замена уравнения на `P = Pref` эквивалентна введению источника, не предусмотренного постановкой.

2. **Epsilon-регуляризация без RHS** математически корректна (баланс точен), но при несжимаемой задаче `‖rhs‖ ≈ 0` → AMG relative tolerance `‖r‖/‖rhs‖` не определена, и AMG зависает.

3. **Правильные подходы** (не реализованы):
   - Малая искусственная сжимаемость `c·∂P/∂t` — добавляет `c·ΔV/τ` к диагонали **и** `c·ΔV/τ·P^n` к RHS. При `c → 0` баланс точный.
   - Проекция решения из ядра после каждого AMG solve (вычитание среднего δP).
   - Режим BHP скважины (P определено скважиной, не нужна регуляризация).

4. **Решение:** пока отказаться от закрытых границ. BHP — проект на будущее (фаза 4).

## Побочные результаты (справочно, всё удалено при откате)
