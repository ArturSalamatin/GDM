# Тесты скважин с переменным дебитом

## Задача
Реализовать тестовые сценарии для скважин с переменными во времени значениями дебита. Знак дебита постоянен, меняется абсолютное значение. Скважина может останавливаться (shut-in).

## Что сделано

### 1. Фабрика `WellScheduleBuilder` (`tests/well_schedule_builder.h`)
Fluent-интерфейс для построения MER-истории скважины:
```cpp
auto well = WellScheduleBuilder(L"INJ", x, y)
    .inject_water(100.0)   // м³/сут, положительное число
    .for_days(90)
    .shut_in().for_days(30)
    .inject_water(150.0)
    .for_days(180);
well.add_to_sim(sim, horizon);
```

- `inject_water(Q)` — закачка воды, Q > 0 в м³/сут, знак инвертируется внутри
- `produce_oil(Q)` — добыча нефти, Q > 0
- `produce_liquid(oil_vol, water_vol)` — добыча смеси
- `shut_in()` — остановка (is_work=0, idle_time=dt, нулевые дебиты)
- `for_days(N)` — генерирует ceil(N/30.74) MER-записей
- `add_to_sim()` — подключает скважину к симулятору

### 2. `VariableDebitCase` (`tests/simulation_cases/VariableDebitCase.h`)
Универсальный `SimulationCase` для тестов с переменным дебитом. Принимает лямбду-конфигуратор, возвращающую вектор `WellScheduleBuilder`. Совместим с `run_case` и визуальной верификацией.

### 3. Тестовые сценарии (`tests/test_variable_debit.cpp`)

| Тест | Сценарий | Результат |
|------|----------|-----------|
| 6.1 | Два периода закачки Q₁=30, Q₂=60 м³/сут (90+180 дней) | ✅ |
| 6.2 | Закачка → shut-in → закачка (60+60+60 дней) | ✅ |
| 6.3 | INJ усиливается (20→40), PROD постоянный 30 м³/сут | ✅ |
| 6.4 | Две INJ попеременно (A работает→B стоит, затем наоборот) | ✅ |

Все тесты проверяют:
- `0 ≤ S_w ≤ 1`, `P > 0` на каждом шаге
- Баланс масс: невязка < 1e-3
- Newton сходится (нет NaN)

### 4. Визуальная верификация
Для всех 4 сценариев сгенерированы `animation.gif` и `mass_balance.png` через `scripts/animate_fields.py`.

## Анализ MER-механизма
`CleanMER_record()` удаляет только leading и trailing нули. Записи с нулевым дебитом **в середине** истории сохраняются — shut-in работает корректно через стандартный MER-механизм без хаков.
