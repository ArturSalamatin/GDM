### 4. Команда `/issue`

Создана slash-команда `.claude/commands/issue.md` для автоматизации создания GitHub issues из vault-записей.

Возможности:
- **Existing mode:** `/issue BUG-002` — находит запись в vault, анализирует код, создаёт issue
- **New mode:** `/issue описание проблемы` — присваивает ID, создаёт запись в vault и issue
- **Dry-run:** `/issue --dry BUG-002` — preview без создания
- Проверка дубликатов (`gh issue list --search`)
- Авто-labels по статусу записи (🔴→critical, 🟡→workaround, Блокирует→blocking)
- Валидация файлов и строк из vault-заметки
- Связывание issues через wiki-ссылки
- Обратная связь в vault (GitHub → vault, vault → GitHub)
- Предложение рабочей ветки: `fix/bug-001/well-state-rollback`
