# Несжимаемость фаз упрощает уравнение неразрывности до дивергенции скорости

## Общее уравнение баланса массы

Для каждой фазы $c = o, w$ уравнение баланса массы:

$$m \frac{\partial (\rho_c s_c)}{\partial t} + \nabla \cdot (\rho_c \mathbf{u}_c) = \dot{q}_c$$

где $m$ — пористость, $\rho_c$ — плотность, $s_c$ — насыщенность, $\mathbf{u}_c$ — скорость фильтрации, $\dot{q}_c$ — источники массы (скважины).

## Упрощение при несжимаемости

При $\rho_c = \mathrm{const}$ плотности выносятся из-под производных. Пористость постоянна во времени (но может быть неоднородна по пространству). Уравнение упрощается до:

$$m \frac{\partial s_c}{\partial t} + \nabla \cdot \mathbf{u}_c = q_c$$

где $q_c$ — объёмный расход фазы.

## Нормированная насыщенность

В документации проекта используется нормированная насыщенность с учётом остаточных значений:

$$\bar{s}_c = \frac{s_c - s_c^{res}}{1 - s_o^{res} - s_w^{res}}$$

Эффективная пористость: $m_{eff} = m(1 - s_o^{res} - s_w^{res})$.

Уравнение баланса в нормированных насыщенностях:

$$m_{eff} \frac{\partial \bar{s}_c}{\partial t} + \nabla \cdot \mathbf{u}_c = q_c$$

## Уравнение для давления — суммирование по фазам

Суммирование уравнений по обеим фазам с учётом $s_o + s_w = 1$ и закона Дарси даёт эллиптическое уравнение для давления:

$$\nabla \cdot (\sigma_t \nabla p) = \sum_c q_c + \nabla \cdot (\sigma_t \bar{\rho} g \nabla z)$$

где $\sigma_t = \sigma_o + \sigma_w$ — суммарная подвижность, $\bar{\rho}$ — средневзвешенная плотность.

## Учёт сжимаемости — расширение модели

В документации (Equations_07292020, раздел «Учёт сжимаемости фаз») показано, как обобщить модель через объёмные коэффициенты $B_i$:

$$B_i = \frac{V_0}{V} \approx B_{i1} (1 + c_i(p - p_1))$$

Типичные значения сжимаемости: $c_w = 10^{-4}$ МПа$^{-1}$, $c_o = 10^{-3}$ МПа$^{-1}$. Линеаризация корректна при перепадах давления $\ll 10^3$ МПа. В текущей постановке GDM фазы несжимаемые — это упрощение.
