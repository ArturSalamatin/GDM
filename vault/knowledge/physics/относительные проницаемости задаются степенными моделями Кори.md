# Относительные проницаемости задаются степенными моделями Кори

## Определение через нормированную насыщенность

В документации GDM фазовые проницаемости заданы степенным законом относительно нормированной насыщенности $\bar{s}$:

$$k_{rw}(\bar{s}_w) = k_{rw}^{0} \cdot \bar{s}_w^{n_w}$$

$$k_{ro}(\bar{s}_w) = k_{ro}^{0} \cdot (1 - \bar{s}_w)^{n_o}$$

где нормированная насыщенность:

$$\bar{s}_w = \frac{s_w - s_{wc}}{1 - s_{wc} - s_{or}}$$

## Параметры модели

| Параметр | Обозначение | Смысл |
|---|---|---|
| Связанная водонасыщенность | $s_{wc}$ (или $s_w^{res}$) | Минимальная насыщенность водой, при которой вода неподвижна |
| Остаточная нефтенасыщенность | $s_{or}$ (или $s_o^{res}$) | Минимальная насыщенность нефтью, при которой нефть неподвижна |
| Показатели Кори | $n_w$, $n_o$ | Характеризуют форму кривых; типичные значения 2–4 |
| Максимальные ОФП | $k_{rw}^{0}$, $k_{ro}^{0}$ | Значения при предельных насыщенностях |

В предыдущей реализации проекта использовался параметр `permPower` (по умолчанию 3) — единый показатель степени для обеих фаз.

## Подвижность фаз

Подвижность фазы $c$:

$$\sigma_c = \frac{k^* k_{rc}(\bar{s})}{\mu_c}$$

где $k^*$ — абсолютная проницаемость пласта, $\mu_c$ — динамическая вязкость.

Суммарная подвижность:

$$\sigma_t = \sigma_o + \sigma_w$$

Доля фазы в потоке (функция Бакли–Леверетта):

$$f_c = \frac{\sigma_c}{\sigma_t}$$
