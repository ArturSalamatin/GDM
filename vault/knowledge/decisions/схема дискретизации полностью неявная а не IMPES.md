# Схема дискретизации полностью неявная, а не IMPES

## Решение

В предыдущей реализации проекта использовалась **полностью неявная (Fully Implicit)** схема дискретизации. Оба документа Equations явно указывают: «Рассматриваются абсолютно неявные схемы». IMPES в документации не упоминается.

## Почему

- Полностью неявная схема **безусловно устойчива** — нет ограничения CFL на шаг по времени
- Для промышленных задач с множеством скважин крупный шаг по времени (месяцы) критичен — мелкие шаги IMPES неприемлемы
- Нелинейная система решается итерациями Ньютона; линейная подзадача — AMG-солвером (amgcl)

## Следствия для реализации

- Матрица СЛАУ **блочная**: каждый блок $2 \times 2$ (уравнение нефти + уравнение воды на ячейку)
- Полный размер: $2n \times 2n$, где $n$ — число активных ячеек
- Нужен якобиан: аналитические производные невязок по $(s_w, p)$
- Нужен модуль `linear_problem` с CRS-хранением блочной матрицы

## Открытый вопрос для GDM

Воспроизводим ли Fully Implicit в новом проекте, или начинаем с IMPES как более простой стартовой точки? IMPES проще в реализации и отладке, но потребует мелких шагов по времени. Fully Implicit сложнее, но масштабируется на промышленные задачи.
