# Команда /plan-improve для планирования рефакторинга

## Назначение

Построение детализированного плана рефакторинга, миграции или очистки, готового к автономной реализации.

## Расположение

`.claude/commands/plan-improve.md`

## Аргумент

`DEBT-NNN` или номер GitHub issue.

## Подтипы

| Подтип | Признак | Шаблон этапов |
|---|---|---|
| **Рефакторинг** | выделение модуля, разбиение | создание → перенос по методу → адаптация вызовов → тесты |
| **Миграция** | FetchContent, замена библиотеки | подключение upstream → локализация патчей → переключение → удаление копии |
| **Удаление** | мёртвый код | доказать мёртвость → удалить по файлу → очистить CMake |
| **Кодировка** | wstring, UTF-8 | инвентаризация → конвертация по файлу → адаптация интерфейсов |
| **Инфраструктура** | CMake, CI, test*.txt | понять текущее → изменить → тесты |

## Фазы работы

1. **Сбор контекста** — vault, GitHub, код, определение подтипа
2. **Анализ** — baseline (тесты, производительность, API), целевое состояние, варианты, чеклист
3. **Детализация** — шаги по шаблону подтипа, каждый компилируется и тесты зелёные
4. **Верификация** — 3 раунда: полнота, корректность, автономность
5. **Сохранение** — файл в `vault/GDM/plans/`, обратные ссылки

## Ключевой инвариант

**После каждого шага проект компилируется и все тесты зелёные.**
