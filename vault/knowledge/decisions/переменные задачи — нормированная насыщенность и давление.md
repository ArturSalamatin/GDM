# Переменные задачи — нормированная насыщенность и давление

## Решение

Система решается в переменных $(\bar{s}_w, p)$, где $\bar{s}_w$ — нормированная насыщенность воды.

## Определение

$$\bar{s}_c = \frac{s_c - s_c^{res}}{1 - s_o^{res} - s_w^{res}}, \quad c = o, w$$

Нормированные насыщенности изменяются от 0 до 1, что упрощает контроль физичности решения. Соотношение $\bar{s}_o + \bar{s}_w = 1$ сохраняется.

## Почему

- Остаточные насыщенности $s_o^{res}$, $s_w^{res}$ вынесены в эффективную пористость $m_{eff} = m(1 - s_o^{res} - s_w^{res})$
- ОФП записываются непосредственно через $\bar{s}$: $k_{rw} = k_{rw}^0 \bar{s}_w^{n_w}$, $k_{ro} = k_{ro}^0 (1 - \bar{s}_w)^{n_o}$ — без дробей с остаточными насыщенностями
- Нефтенасыщенность определяется из замыкания: $\bar{s}_o = 1 - \bar{s}_w$, в систему уравнений явно не входит

## Следствия

- В блочной матрице $2 \times 2$: первая строка — баланс нефти, вторая — баланс воды; неизвестные $(\delta \bar{s}_w, \delta p)$
- При инициализации: пересчёт из «сырых» $s_w$ в нормированные $\bar{s}_w$
- При выводе результатов: обратный пересчёт $s_w = \bar{s}_w (1 - s_o^{res} - s_w^{res}) + s_w^{res}$
