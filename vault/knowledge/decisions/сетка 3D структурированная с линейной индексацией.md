# Сетка 3D структурированная с линейной индексацией

## Решение

Расчётная область — 3D структурированная сетка из прямоугольных параллелепипедов. Ячейки нумеруются тройкой индексов $(i, j, k)$ с глобальным линейным индексом:

$$l = i + n_x j + n_x n_y k$$

где $i = 0 \ldots n_x - 1$, $j = 0 \ldots n_y - 1$, $k = 0 \ldots n_z - 1$.

## Свойства сетки

- Шаги $h_x$, $h_y$ — **однородные** в горизонтальной плоскости
- Шаг $h_z$ — **переменный** по слоям; высота ячейки вычисляется как $h_z = V_l / (h_x h_y)$
- Ось $z$ направлена **вертикально вниз** (вдоль силы тяжести)
- Площади граней ⊥ оси $z$: $h_x h_y$; площади граней ⊥ осям $x$, $y$: с полусуммой высот двух смежных ячеек

## Активные и неактивные ячейки

Из документации (ReservoirSimulator_01052021):

- Вектор `activeCells` (размер $n_x n_y n_z$): `true` — активная, `false` — неактивная
- Неактивные ячейки исключаются из системы уравнений
- Число уравнений: $n_x n_y n_z - J$, где $J$ — число неактивных ячеек

## Связность ячеек

Граф связности `connectivityGraph` — вектор векторов: для каждой ячейки $i$ хранит номера соседних (смежных по грани) ячеек в порядке возрастания. Определяет шаблон разреженности матрицы СЛАУ.
