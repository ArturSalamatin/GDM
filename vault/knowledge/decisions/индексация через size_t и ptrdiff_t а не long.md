# Индексация через size_t и ptrdiff_t, а не long

## Решение

Для индексов и размеров контейнеров используются:
- `size_t` — беззнаковый тип для размеров и индексов
- `ptrdiff_t` — знаковый тип для разностей указателей и знаковых индексов

`long` и `int` **не используются** для индексации.

## Почему

На Windows (MSVC, LLP64-модель) `long` = 32 бита даже в x64-сборке. `size_t` и `ptrdiff_t` = 64 бита в x64. Использование `long` для индексов — это неявное сужение 64→32 бит (warning C4244) и потенциальное переполнение на больших сетках.

AMGCL и Eigen возвращают `ptrdiff_t` в своих интерфейсах. Приведение к `long` маскирует проблему кастом вместо решения.

## Правило

Если внешняя библиотека возвращает `ptrdiff_t` — принимать как `ptrdiff_t`. Не кастовать в `long` или `int`. См. [[локальные патчи AMGCL для GDM]].

Если STL-контейнер возвращает `size_t` — использовать `size_t`. Не кастовать в `int`.
