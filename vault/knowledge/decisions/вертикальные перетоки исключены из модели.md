# Вертикальные перетоки исключены из модели

В постановке задачи вертикальные (Z) перетоки между пластами исключены. Многопластовая система моделируется как стопка независимых 2D-слоёв: каждый слой решается отдельно, связь между слоями — только через общие скважины.

В коде это отражено в `SetConnectivityGraph_3D` ([[AbstractGrid.h]]):
- Z-связи закомментированы (строки ~226–232, 262–267).
- Connectivity graph содержит только X- и Y-соседей.

**Следствие для тестов:** сетки 2×2×2 и 3×3×3 — это стопки независимых 2D-слоёв. Матрица блочно-диагональная по слоям. Тесты должны это учитывать.
