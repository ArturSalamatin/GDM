# Полностью неявная схема линеаризуется методом Ньютона

## Контекст

Документация проекта использует **полностью неявную (Fully Implicit)** схему, а не IMPES. Обе переменные — давление $p$ и насыщенность $s_w$ — определяются неявно на новом временном слое. Это требует решения нелинейной системы на каждом шаге по времени.

## Линеаризация по Ньютону

Нелинейная система $F(y^{\alpha+1}) = 0$ линеаризуется:

$$\frac{\partial F}{\partial y}\bigg|^{\alpha} \delta y = -F(y^{\alpha})$$

где $\alpha$ — номер итерации, $\delta y = y^{\alpha+1} - y^{\alpha}$ — поправки.

Обновление:

$$y^{\alpha+1} = y^{\alpha} + \delta y$$

## Блочная структура матрицы

Вектор неизвестных группируется по ячейкам: $\delta y = (\delta s_w, \delta p)_0, (\delta s_w, \delta p)_1, \ldots$

Матрица якобиана $A$ имеет блочную структуру:
- Каждый блок $A_{ij}$ — матрица $B \times B$, где $B = 2$ (два уравнения на ячейку: баланс нефти + баланс воды)
- Диагональный блок $A_{ll}$ — собственная ячейка
- Внедиагональные блоки $A_{ll'}$ — смежные ячейки (по графу связности сетки)
- На структурированной 3D-сетке: до 7 блоков в строке (сам + 6 соседей)

Полный размер матрицы: $nB \times nB$, где $n$ — число активных ячеек.

## Хранение — CRS с блочной структурой

Реализация через модуль `linear_problem` (LinearProblemModule_01092021.docx):
- `SparsityPattern` — шаблон разреженности с графом связности ячеек
- `MatrixCSR` — хранение в CRS-формате; методы `AddDiagBlock(l, data)` и `AddOffDiagBlock(l, neibIdx, data)`
- `LinearProblem` — интерфейс для заполнения и решения СЛАУ
- Солвер: итерационный алгебраический многосеточный метод (AMG) через библиотеку **amgcl**

## Сравнение с IMPES

| | Fully Implicit | IMPES |
|---|---|---|
| Устойчивость | Безусловная | Ограничена CFL |
| Шаг по времени | Крупный | Мелкий |
| Стоимость шага | Решение нелинейной системы (итерации Ньютона) | Одна линейная система + явный шаг |
| Размер СЛАУ | $2n \times 2n$ (блочная) | $n \times n$ (скалярная для давления) |
| Реализация | Сложнее | Проще |
