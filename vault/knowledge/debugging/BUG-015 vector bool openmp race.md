# BUG-015: std::vector\<bool\> под OpenMP — data race в UpdateGrid()

## Симптом

Потенциальное повреждение флагов сходимости Newton-итерации при параллельной записи. Ложная сходимость или ложная несходимость — недетерминистично.

## Причина

`UpdateGrid()` использовал `std::vector<bool> f` для хранения флагов сходимости. Вектор заполнялся внутри `#pragma omp parallel for`. Специализация `vector<bool>` хранит элементы как биты — 8 элементов в одном байте. Два потока, пишущие в разные биты одного байта, выполняют read-modify-write без синхронизации = data race (UB по C++ стандарту).

При `B = 2` (constexpr — насыщенность + давление), элементы `f[2*l]` и `f[2*l+1]` для 4 соседних ячеек делят один байт.

## Решение

Замена `std::vector<bool>` на `std::vector<char>`. Каждый `char` занимает свой байт — параллельная запись в разные элементы безопасна (ISO C++ §6.9.2.2). 2 строки изменений.
