# BUG-020: несогласованность единиц расхода в формуле Писмана

## Симптом

Забойное давление добывающей скважины уходит в отрицательные значения (~-8.5e7 Па). Баланс масс не сходится. Тесты `mass_balance` и `volume_balance` падают.

## Корневая причина

`SetRefWellPressure` складывала величины разной размерности:

```
numer = -CurOverallDebit() [кг/день] + Σ factor·λ·P_res [м³/(Па·день)·Па = м³/день]
```

`CurOverallDebit()` возвращает массовый расход из MER (кг/день), а `factor·λ·OverallMobility·P` — объёмный (м³/день). Знаменатель `denom = Σ factor·λ` тоже в м³/(Па·день). Дробь `numer/denom` давала абсурдное давление.

## Решение

### Основной фикс (три файла)

**SetRefWellPressure** (`Wells.cpp`): ввести `ρ_mix = ρ_oil·F_Oil + ρ_water·(1-F_Oil)` как множитель:

```
numer = -CurOverallDebit() [кг/день] + Σ ρ_mix·factor·λ·P_res [кг/день]
denom = Σ ρ_mix·factor·λ [кг/(Па·день)]
P_well = numer/denom [Па]  ✓
```

**rhs** (`Wells.cpp`): `rhs_oil = -ρ_oil · F_Oil · production`, `rhs_water = -ρ_water · (1-F_Oil) · production`. Переводит объёмный production [м³/день] в массовый поток [кг/день], согласованный с межблочными потоками.

**Якобиан** (`Wells.cpp`): все производные ∂rhs/∂Sw и ∂rhs/∂P умножены на соответствующие ρ_oil / ρ_water.

**CellDensityOil/CellDensityWater** (`SomeWell.cpp`, `SomeWell.h`): новые accessor'ы для плотности ячеек перфорации.

### Вторичный фикс — согласование баланса масс

После основного фикса 13 тестов падали с невязкой баланса масс 0.15-3.4%. Причина: в симуляторе два независимых пути подсчёта скважинного дебита:

1. **Матричное уравнение** (rhs) — теперь с ρ, корректно
2. **MassBalance()** → `OilDebitTotal()` → `CurOilDebit_Num()` — без ρ, рассогласовано

`CurOilDebit_Num()` вычисляла `CurOverallDebit() · F_OilWellBalance`, где `F_OilWellBalance` определялась в `BalanceOil()` через сравнение объёмных `productions` [м³/день] с массовым `CurOverallDebit()` [кг/день].

**Исправление:**
- `BalanceOil()` (`SomeWell.cpp`): заменить `CurOverallDebit()` на `Σ productions[l]` — объёмный баланс в м³/день
- `CurOilDebit_Num()` / `CurWaterDebit_Num()` (`SomeWell.cpp`): вычислять из `Σ ρ·F_Oil·production` — в точности rhs с обратным знаком

## Урок

При изменении единиц/размерности в формуле — проследить ВСЕ параллельные пути, где та же величина вычисляется другим способом. Если основной путь (rhs) изменён, а проверочный (MassBalance) — нет, невязка неизбежна. Компилятор не ловит размерные ошибки.
